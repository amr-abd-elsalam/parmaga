    KEY TERMS

    صفحة الويب Web Page: مستند يُعرض في المتصفح، يُكتب أساسًا بلغة HTML.

    Web page: a document shown in a browser, written mainly in HTML.

    الموقع الإلكتروني Website: مجموعة صفحات مترابطة؛ الموقع كتاب والصفحة ورقة منه.

    Website: a group of linked pages; the site is a book and a page is one sheet.

    Browser: a program that reads HTML, CSS, and JavaScript and turns them into a page you can see and use.

    العميل Client والخادم Server: العميل جهازك ومتصفحك يطلب الصفحة، والخادم حاسوب يرسلها إليه، كالزبون والنادل.

    Client and server: the client, your device and browser, requests the page; the server, a computer, sends it, like a customer and a waiter.

    مصطلحات أساسية

    KEY TERMS

    ‏HTML: اختصار HyperText Markup Language، أي لغة ترميز النص التشعبي؛ تصف بنية الصفحة بالوسوم.

    HTML: short for HyperText Markup Language; it describes the page's structure using tags.

    الوسم Tag: كلمة بين قوسين زاويين تحدد نوع المحتوى، مثل <p> للفقرة.

    Tag: a word between angle brackets that sets the type of content, such as <p> for a paragraph.

    العنصر Element: الوسم الافتتاحي ومحتواه والوسم الختامي معًا، مثل <p>Hello</p>.

    Element: the opening tag, its content, and the closing tag together, such as <p>Hello</p>.

    ‏CSS: اختصار Cascading Style Sheets، أي أوراق الأنماط المتتالية؛ تحدد الألوان والخطوط والأحجام والتخطيط.

    CSS: short for Cascading Style Sheets; it sets colors, fonts, sizes, and layout.

    معلومة تميّزك

    STAND-OUT FACT

    ‏HTML وCSS ليستا لغتي برمجة: HTML لغة ترميز تصف المحتوى، وCSS لغة تنسيق. أما JavaScript فلغة برمجة فيها شروط وتكرار وحسابات.

    HTML and CSS are not programming languages: HTML is a markup language that describes content, and CSS is a style language. JavaScript is a programming language with conditions, loops, and calculations.

    التفاعلية Interactivity: قدرة الصفحة على الاستجابة لأفعالك، كالنقر والكتابة.

    Interactivity: the page's ability to respond to your actions, like clicking and typing.

    التحقق من المدخلات Validation: فحص ما تكتبه في النموذج قبل إرساله؛ وتقدر HTML على تحقق بسيط مثل required، والمخصص بـ JavaScript.

    Validation: checking what you type in a form before sending it; HTML can do simple checks like required, and custom checks use JavaScript.

    معلومة تميّزك: المكتبة أم إطار العمل؟

    Stand-Out Fact: Library or Framework?

    المكتبة Library مثل صندوق العدة: أنت تختار الأداة وتستدعيها وقتما تحتاج.

    A library is like a toolbox: you pick the tool and call it when you need it.

    إطار العمل Framework مثل قالب البيت الجاهز: هو يحدد الهيكل والقواعد، وأنت تملأ الأماكن التي حددها.

    A framework is like a ready house frame: it sets the structure and rules, and you fill the places it defines.

    مع المكتبة: أنت تستدعي الكود. مع الإطار: الإطار يستدعي كودك.

    With a library, you call the code. With a framework, the framework calls your code.

    Exam Traps: ○ or ×?

    ‏× CSS تضيف سلوكًا إلى الصفحة. ‏← CSS للمظهر، والسلوك لـ JavaScript.

    × CSS adds behavior to the page. → CSS is for appearance; behavior is JavaScript.

    ‏× HTML الدلالية تجعل الصفحة أسرع بالضرورة. ← فائدتها الفهم: إمكانية الوصول وSEO.

    × Semantic HTML necessarily makes the page faster. → Its benefit is understanding: accessibility and SEO.

    ‏× HTML الدلالية تضمن المركز الأول في البحث. ← تساعد ولا تضمن.

    × Semantic HTML guarantees first place in search. → It helps but does not guarantee.

    × التصميم المتجاوب لرفع الترتيب في البحث. ← سببه تنوع الأجهزة.

    × Responsive design is for raising search ranking. → Its reason is the variety of devices.

    Model Answer

    ‏HTML (درجتان): تبني بنية الصفحة، فتضع العنوان وقائمة الكتب وخانة البحث.

    HTML (2 marks): builds the page's structure, placing the heading, the book list, and the search box.

    ‏CSS (درجتان): تحدد مظهر الصفحة، مثل ألوان المكتبة والخطوط وعرض الكتب في بطاقات.

    CSS (2 marks): sets the page's appearance, such as the library's colors, the fonts, and showing books as cards.

    ‏JavaScript (درجتان): تضيف السلوك، فتستجيب لكتابة المستخدم في خانة البحث وتعرض الكتب المطابقة فقط دون إعادة تحميل الصفحة.

    JavaScript (2 marks): adds behavior, responding to what the user types in the search box and showing only matching books without reloading the page.
