    مصطلحات أساسية

    KEY TERMS

    الخوارزمية Algorithm — خطوات مرتبة لحل مشكلة، مثل وصفة الطبخ.

    Algorithm — ordered steps to solve a problem, like a recipe.

    البرمجة الصريحة Explicit Programming — يكتب المبرمج كل قاعدة بنفسه: «إذا حدث كذا، فافعل كذا».

    Explicit programming — the programmer writes every rule: "If this happens, then do that."

    التعلّم الآلي Machine Learning — فرع من الذكاء الاصطناعي يتعلم الأنماط من البيانات بدلًا من برمجة كل قاعدة.

    Machine learning — a branch of AI that learns patterns from data instead of programming every rule.

    KEY TERMS

    البيانات Data — الأمثلة التي يتعلم منها النموذج: صور ونصوص وأرقام.

    Data — the examples a model learns from: images, text, and numbers.

    بيانات التدريب Training Data — الجزء من البيانات الذي نعلّم به النموذج.

    Training data — the part of the data we use to teach the model.

    القاعدة الذهبية: جودة النموذج من جودة بياناته.

    Golden rule: a model is only as good as its data.

    KEY TERMS

    العصبون الاصطناعي Artificial Neuron — الوحدة الأصغر في الشبكة: يضرب كل مدخل في وزنه، ويجمع النتائج، ثم يقرر ماذا يمرّر.

    الوزن Weight — رقم يحدد أهمية كل مدخل؛ والتعلّم كله هو ضبط هذه الأوزان.

    Weight — a number that sets how important each input is; learning is really adjusting these weights.

    مصطلحات أساسية

    KEY TERMS

    الشبكة العصبية الاصطناعية Artificial Neural Network (ANN) — نموذج حاسوبي مستوحى بصورة مبسطة من ترابط الخلايا العصبية، من وحدات متصلة في طبقات تتغير أوزانها أثناء التدريب.

    Artificial neural network (ANN) — a computer model loosely inspired by connected nerve cells, made of units connected in layers whose weights change during training.

    انتبه: مستوحاة من الدماغ، وليست نسخة منه.

    Note: it is inspired by the brain; it is not a copy of it.

    طبقات الشبكة

    Network layers

    طبقة الإدخال Input Layer — تستقبل البيانات الخام، مثل بكسلات الصورة.

    Input layer — receives the raw data, like the pixels of an image.

    الطبقة المخفية Hidden Layer — بين الإدخال والإخراج، تعالج البيانات وتستخرج خصائصها.

    Hidden layer — between input and output; it processes data and extracts its features.

    طبقة الإخراج Output Layer — تعطي النتيجة النهائية، مثل «قطة بنسبة 95%».

    Output layer — gives the final result, like "cat: 95%".

    Stop 3: Deep Learning… A Factory Line

    الشبكة «العميقة» فيها طبقات مخفية كثيرة، وكل طبقة تفهم أكثر مما قبلها.

    A "deep" network has many hidden layers; each one understands more than the last.

    تابع صورة قطة وهي تدخل الشبكة:

    Follow a cat photo as it enters the network:

    الطبقة الأولى تلاحظ خطوطًا وحوافّ.

    The first layer notices lines and edges.

    الطبقة التالية تجمع الخطوط في أشكال.

    The next layer combines lines into shapes.

    التي بعدها ترى عيونًا وآذانًا وشوارب.

    The one after sees eyes, ears, and whiskers.

    الطبقة الأخيرة تقرر: «قطة».

    The last layer decides: "cat".

    وكذلك النموذج: يتعثّر مع الشيء الذي نادرًا ما رآه في بياناته، لأنه لم يتعلّم نمطه.

    The same goes for a model: it struggles with things it has rarely seen in its data, because it never learned their pattern.

    مصطلحات أساسية

    KEY TERMS

    التعلم العميق Deep Learning — أسلوب من التعلّم الآلي يستخدم شبكات عصبية بطبقات مخفية كثيرة، ويحتاج غالبًا إلى بيانات كثيرة وقدرة حاسوبية كبيرة.

    Deep learning — a type of machine learning that uses neural networks with many hidden layers; it usually needs a lot of data and computing power.

    التمثيل Representation — طريقة وصف النموذج للبيانات داخليًا بالأرقام: خطوط، ثم أشكال، ثم ملامح.

    Representation — how a model describes data inside itself using numbers: lines, then shapes, then features.

    Generative AI — systems that create new content (text, images, audio, and code) from the patterns they learned; most modern systems are built on deep learning.

    KEY TERMS

    النموذج اللغوي الكبير Large Language Model (LLM) — نموذج توليدي دُرِّب على نصوص هائلة، ويولّد النص بالتنبؤ بالكلمة التالية، وعليه بُني ChatGPT.

    Stop 5: Hallucination… The Student Who Makes Things Up

    كلنا نعرف الطالب الذي لا يعرف الإجابة، لكنه يكتب صفحة كاملة بثقة وبخط جميل وكلام مرتب…

    We all know the student who doesn't know the answer, but writes a full page confidently, in neat handwriting and well-ordered sentences…

    ثم يقرأ المصحح، فيجد الكلام كله خطأ!

    Then the teacher reads it and finds it is all wrong!

    هذه هي الهلوسة: كلام يبدو مقنعًا وواثقًا، لكنه خاطئ أو مختلق.

    This is hallucination: text that sounds convincing and confident, but is wrong or made up.

    لماذا يحدث ذلك؟

    Why does it happen?

    النموذج التوليدي مصمَّم ليُنتج كلامًا محتملًا لغويًا، لا ليتحقق من أنه صحيح واقعيًا.

    A generative model is designed to produce text that is likely in language, not to check that it is true in fact.

    لذلك قد يخترع معلومة أو تاريخًا أو حتى مرجعًا غير موجود.

    So it may invent a fact, a date, or even a source that does not exist.

    Narrow AI — a system designed for a specific task or a limited set of tasks; it is what we use today.

    الذكاء الاصطناعي العام Artificial General Intelligence (AGI) — فكرة نظرية لنظام يؤدي أي مهمة فكرية يؤديها الإنسان، ولم يتحقق حتى الآن.

    Artificial general intelligence (AGI) — a theoretical system that could do any intellectual task a human can; it has not been achieved yet.
