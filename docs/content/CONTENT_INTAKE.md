# Parmaga — إجراء إدخال المحتوى وحراسة الأصول

> إجراء تشغيلي يتبعه مالك المشروع بعد كل Session أوفلاين.
>
> المرجع الحاكم: `ADR-0005`. المعرّفات والمسارات: `ADR-0004`. معمارية الدروس: `ADR-0003`.
>
> هذا الملف لا يصف حالة منشورة. هو خطوات تُنفَّذ قبل النشر.

---

## ⚠ تحذير قبل أي أمر

**كل أمر في هذا الملف أمر قراءة فقط.**

لا يوجد في هذا الإجراء أمر واحد يكتب أو يعدّل أو يعيد حفظ أصلًا. أي أمر من الأنواع التالية ممنوع داخل هذا الإجراء:

- `rm` أو `mv` أو أي حذف أو نقل للأصول.
- `sed -i` أو أي تعديل في المكان.
- `svgo` أو `scour` أو أي مُحسِّن أو مُنظِّف SVG.
- إعادة التصدير أو إعادة الحفظ من أي محرّر رسومي.
- إعادة تنسيق أو ضغط أو تغيير نهايات أسطر أي ملف SVG.
- أي إعادة توجيه مخرجات إلى ملف داخل مجلد الأصول.

تعديل أصل بأي صورة يُبطل بصمته ويكسر سلسلة التحقق الثلاثية. إن تعدّل أصل بالخطأ، أعِد النسخة السليمة من الحراسة وأعِد الجرد من البداية.

**لا تفتح ملفات SVG بأداة قد تعيد حفظها تلقائيًا.**

## 1. تجهيز الأصول

1. اجمع أصول الدرس الواحد في مجلد عمل واحد.
2. أبقِ سلسلة الطالب وحدها. مجموعة «شرح المدرس» مستبعدة نهائيًا وفق `ADR-0005` البند 5.
3. تحقق أن العدد مطابق للعدد المتوقع للدرس.
4. حدّد الصفحة الافتتاحية وترتيب صفحات المحتوى بعدها.
5. لا تحرّر أي ملف. لا تفتحه في محرّر رسومي.
6. تأكد أن نسخة المصدر الأصلية باقية في مكانها دون تغيير.

## 2. النسخ إلى مسار الحراسة القانوني

انسخ الأصول مع الحفاظ على الخصائص إلى نسخة العمل داخل `parmaga-content`، تحت مسار يعكس مسار النشر:

```text
assets/lessons/<course>/<term>/<chapter>/<lesson>/
```

النسخ يحافظ على الخصائص، والأصل يبقى في مكانه. لا نقل ولا حذف.

يجب أن توجد عند نهاية هذه الخطوة ثلاث نسخ: المستودع الخاص، والنسخة المحلية، والنسخة الأوفلاين المستقلة.

## 3. إعادة التسمية إلى النمط القانوني

الاسم القانوني وفق `ADR-0004 §18`:

```text
page-<NNN>.svg
```

بتصفير إلى ثلاث خانات: `page-001.svg`، `page-002.svg`، `page-027.svg`. وإذا تجاوز عدد الصفحات 999 يستمر الرقم طبيعيًا دون إعادة تسمية ما قبله.

قواعد ملزمة:

- الرقم يتبع ترتيب العرض المعتمد للدرس، لا ترتيب التوليد ولا ترتيب النظام الأبجدي.
- الأسماء الاعتباطية ممنوعة: `final.svg`، `new-page.svg`، `image-copy.svg`، `lesson-page-final-2.svg`.
- المطابقة مع المرساة حتمية: `#page-1` ⇄ `page-001.svg`، و`#page-27` ⇄ `page-027.svg`.
- إذا كانت الأسماء الواردة من التوليد مطابقة للنمط أصلًا، لا تفعل شيئًا، وسجّل أن `sourceFileName` يساوي `file`.
- إعادة التسمية تجري **في مسار الحراسة**، لا على نسخة المصدر الأصلية.
- تغيير الاسم لا يغيّر بايتات الملف ولا بصمته.

## 4. الجرد: البصمات والأحجام والأبعاد والتحليل والخطوط والفحص الأمني

من داخل مجلد أصول الدرس في مسار الحراسة، شغّل أمر الجرد الموحّد. مخرجاته هي المصدر الوحيد لقيم الـManifest.

```bash
python3 - <<'PY'
import glob, hashlib, re, json
import xml.etree.ElementTree as ET

files = sorted(glob.glob('*.svg'))
print("FILE_COUNT", len(files))
total = 0
for f in files:
    b = open(f, 'rb').read()
    total += len(b)
    r = {"sourceFileName": f, "bytes": len(b),
         "sha256": hashlib.sha256(b).hexdigest(),
         "bom": b[:3] == b'\xef\xbb\xbf', "crlf": b'\r\n' in b}
    m = re.match(rb'<\?xml[^>]*encoding\s*=\s*["\']([^"\']+)', b.lstrip()[:300])
    r["encodingDeclared"] = m.group(1).decode('ascii', 'replace') if m else None
    try:
        root = ET.fromstring(b)
        r["xmlWellFormed"] = True
        r["width"] = root.get('width')
        r["height"] = root.get('height')
        r["viewBox"] = root.get('viewBox')
        tags = [e.tag for e in root.iter() if isinstance(e.tag, str)]
        r["textElementCount"] = sum(1 for t in tags if t.endswith('text'))
        r["tspanCount"] = sum(1 for t in tags if t.endswith('tspan'))
    except Exception as e:
        r["xmlWellFormed"] = False
        r["xmlError"] = str(e)
    s = b.decode('utf-8', 'replace')
    fonts = set()
    for g in re.findall(r'font-family\s*[:=]\s*("[^"]*"|\'[^\']*\'|[^;">}]+)', s):
        for part in g.strip().strip('"\'').split(','):
            p = part.strip().strip('"\'')
            if p:
                fonts.add(p)
    r["fontsReferenced"] = sorted(fonts)
    r["hasScript"] = bool(re.search(r'<\s*(\w+:)?script\b', s))
    r["hasForeignObject"] = bool(re.search(r'<\s*(\w+:)?foreignObject\b', s))
    r["hasEventHandlers"] = bool(re.search(r'\son[a-zA-Z]+\s*=\s*["\']', s))
    r["hasJavascriptUri"] = 'javascript:' in s
    r["hasExternalHttpRef"] = bool(re.search(r'(?:xlink:href|href|src)\s*=\s*["\']\s*https?:', s)) or bool(re.search(r'url\(\s*["\']?\s*https?:', s))
    r["hasDataUri"] = bool(re.search(r'["\'(]\s*data:', s))
    r["hasEmbeddedImage"] = bool(re.search(r'<\s*(\w+:)?image\b', s))
    r["hasExternalUse"] = bool(re.search(r'<\s*(\w+:)?use\b[^>]*?(?:xlink:)?href\s*=\s*["\'][^#"\']', s))
    r["hasIframeEmbedObject"] = bool(re.search(r'<\s*(\w+:)?(iframe|embed|object)\b', s))
    r["hasStyleImport"] = '@import' in s
    ys = [float(y) for y in re.findall(r'\sy\s*=\s*["\']\s*(-?\d+(?:\.\d+)?)', s)]
    r["maxYAttr"] = max(ys) if ys else None
    r["yAttrsBelow1188"] = sum(1 for y in ys if y > 1188)
    print(json.dumps(r, ensure_ascii=False))
print("TOTAL_BYTES", total)
print("AVG_BYTES", total // len(files) if files else 0)
PY
```

ثم تأكيد مستقل بأدوات نظام مختلفة، لإثبات أن قيم البصمات والأحجام لا تعتمد أداة واحدة:

```bash
sha256sum *.svg
stat -c '%s  %n' *.svg
```

ملاحظات على قراءة المخرجات:

- `encodingDeclared: null` مع `bom: false` مع `xmlWellFormed: true` يعني أن الملف UTF-8 بلا إعلان. الترميز هنا **مستنتج** من نجاح التحليل، لا مقروء من إعلان، ويُسجَّل كذلك.
- `crlf: true` يعني أن نهايات الأسطر داخل الأصل CRLF. لا تصححها. `.gitattributes` موجود لحماية هذه الحالة تحديدًا.
- `maxYAttr` و`yAttrsBelow1188` مؤشران على احترام منطقة الـ12% المحجوزة، حدّها `y = 1188` في صفحة بارتفاع 1350. القياس على سمات `y` وحدها ولا يحسب `transform` ولا `path` ولا `y+height` ولا `cy+r`. مؤشر قوي وليس إثباتًا هندسيًا كاملًا.
- `AVG_BYTES` قيمة مقيسة. لا تكتب في الـManifest متوسطًا تقديريًا.

## 5. تحليل XML

نتيجة التحليل تأتي من الحقل `xmlWellFormed` في مخرجات الخطوة 4.

`false` في أي ملف يوقف الإجراء. لا يُصلَح الملف بالتحرير؛ يُعاد توليده من القالب ويُعاد جرده من الخطوة 1.

## 6. الفحص الأمني

نتائج الفحص العشرة تأتي من الخطوة 4 نفسها. سجّلها كلها لكل صفحة، حتى إن كانت كلها سالبة.

قاعدة الحكم وفق `ADR-0005` البند 9:

- كل اكتشاف يُسجَّل في `findings`.
- لكل اكتشاف قرار مكتوب: قبول بمبرر، أو منع نشر، أو إعادة توليد.
- **لا يُعالَج اكتشاف بتعديل الأصل.**
- الاسم الصحيح للملف لا يمنح ثقة، ولا يغني عن الفحص.

## 7. تعبئة الـManifest

المسار:

```text
docs/content/manifests/<course>/<term>/<chapter>/<lesson>.json
```

القواعد:

- JSON صالح، UTF-8 بلا BOM، نهايات أسطر LF.
- كل قيمة تأتي من ناتج أمر حقيقي أو من تأكيد مكتوب من مالك المشروع.
- ما لا يتوفر يُكتب `null`، ويُكتب سبب النقص في `notes`.
- **ممنوع اختراع قيمة أو تقديرها.**
- ترقيم متصل من `001` بلا فجوة ولا تكرار، ومطابق لـ`declaredPageCount`.
- الصفحة الافتتاحية `role: "opening"`، وبقية الصفحات `role: "content"`.
- `status` يساوي `"inventoried"` في هذه المرحلة، ولا يصبح `"published"` إلا في commit النشر.

## 8. توليد الـContext Packet

المسار:

```text
docs/content/context/<course>/<term>/<chapter>/<lesson>.md
```

القواعد:

- السقف ثمانية كيلوبايت.
- **بلا أي وسم SVG.**
- مشتق من الـManifest ولا يضيف بيانات ليست فيه.
- سطر واحد لكل صفحة يجمع المعرّف والدور والأبعاد والحجم ونتيجة الفحص والوصف العربي.
- يذكر القيود المعروفة صراحة: الخطوط، الألوان خارج نطاق Design Tokens، منطقة الـ12% المحجوزة.
- يفصل بوضوح بين ما هو محسوم وما هو غير محسوم.
- يُختم بفقرة «كيف تستخدم هذا الملف».

لا تدخل `docs/content/` أجوبةٌ ولا محتوى امتحانات ولا بيانات طلبة ولا أرشيف برومبتات ولا نص الدرس الكامل، وفق `ADR-0005` البند 13.

## 9. الإيداع في المستودع الخاص

أودِع في `parmaga-content`: الأصول بأسمائها القانونية، وبرومبتات التوليد، وملفات `.md` المجمّعة، ونسخة من مخرجات الجرد الخام.

تأكد أن Pages غير مفعَّل على `parmaga-content`، وأنه ما زال خاصًا.

لا شيء من أرشيف البرومبتات والملفات المجمّعة يدخل المستودع العام.

**الأصول لا تدخل `main` في هذه المرحلة.** دخولها يكون في commit نشر الدرس نفسه فقط، وفق قاعدة الحاجز في `ADR-0005` البند 3.

## ماذا تفعل عند اكتشاف مشكلة

### فجوة في الترقيم

مثال: `page-014.svg` غير موجود بين `013` و`015`.

توقف. لا تُزحزح الأرقام لسدّ الفجوة، ولا تُعِد تسمية `015` إلى `014`. الفجوة إما ملف مفقود من التوليد، وحينها يُعاد توليده ويُجرد ويُدرج في موضعه، أو صفحة أُلغيت قصدًا، وحينها يُثبَّت العدد الجديد كتابةً ويُعاد الترقيم **قبل** أي نشر ولن يُعاد بعده. إذا كان الدرس منشورًا فعلًا فلا إعادة ترقيم مطلقًا، والحالة تصبح Migration مستقلة وفق `ADR-0004 §20`.

### عدد غير مطابق للعدد المتوقع

توقف قبل الـManifest. لا تكتب `declaredPageCount` مطابقًا لعدد الملفات لتُخفي الفارق. سجّل العددين، وحدّد سبب الفارق: مجموعة شرح مدرس لم تُستبعد، أو ملف مكرر، أو ملف نُسخ ناقصًا، أو صفحة لم تُولَّد. لا يمضي الإجراء قبل تفسير الفارق وإقرار العدد الصحيح كتابةً.

### بصمة مكررة بين ملفين

بصمتان متطابقتان تعنيان ملفين متطابقين بايتًا ببايت. أي أن صفحة نُسخت مرتين باسمين، أو صفحة كُتبت فوق أخرى. توقف. حدّد الصفحة الصحيحة، وأعِد الناقصة من الحراسة أو من التوليد، ولا تنشر بصمة مكررة. تكرار البصمة مع اختلاف الاسم يعني أن أحد الأرقام يشير إلى محتوى خطأ، وهو خطأ تعليمي لا تقني فقط.

### ملف لا يُحلَّل

`xmlWellFormed: false` يوقف الإجراء لذلك الملف. لا تُصلح الوسوم يدويًا ولا تفتحه في محرّر يعيد الحفظ؛ الإصلاح اليدوي يغيّر البايتات ويخفي سبب الخطأ في القالب. سجّل رسالة الخطأ، وأعِد توليد الملف من القالب، وأعِد جرده من الخطوة 1. إن تكرر الخطأ في أكثر من ملف فالمشكلة في القالب لا في الملف، وعلاجها في القالب القادم.

### اكتشاف أمني

أي قيمة موجبة في الفحص توقف نشر الدرس حتى يُكتب قرار. سجّل الاكتشاف في `findings` بنوعه وموضعه. القرارات الممكنة ثلاثة فقط: قبول بمبرر مكتوب إذا كان الاكتشاف غير تنفيذي وغير شبكي وموثَّقًا، أو منع نشر الصفحة، أو إعادة توليد الأصل من القالب. **لا يُعالَج الاكتشاف بتعديل الأصل** ولا بحذف عنصر منه. وجود `script` أو `foreignObject` أو سمة `on*` أو مرجع شبكي خارجي يُعامل بوصفه مانع نشر افتراضيًا، لا اكتشافًا يُقبل بمبرر.

### نهايات أسطر تغيّرت أو بصمة اختلفت بين حلقتين

اختلاف البصمة بين ما قبل الـcommit وما بعده يعني أن Git طبّع الملف. تحقق من `.gitattributes` ومن `git config --get core.autocrlf` و`git ls-files --eol`. لا تُحدّث البصمة في الـManifest لتطابق الملف الجديد؛ ذلك يخفي السبب. أعِد الملف السليم من الحراسة، أصلح الإعداد، ثم أعِد الجرد.
