# ADR-0001: الاستضافة والتوجيه وسلوك صفحة 404

## Status

Accepted

## Context

يعمل موقع Parmaga حاليًا كموقع HTML وCSS ثابت مستضاف مؤقتًا على GitHub Pages، مع وجود Cloudflare أمام الموقع.

لا توفر GitHub Pages في هذا الإعداد Rewrites أو Custom Headers، ولا يمكن استخدامها لتقديم SPA fallback بحالة HTTP 200 للمسارات غير الموجودة. ملف `404.html` يُقدَّم بحالة HTTP 404، وهذا هو السلوك الصحيح للمسارات غير الموجودة.

كانت صفحة `404.html` تحول الزائر قسريًا إلى الصفحة الرئيسية باستخدام `meta refresh` وJavaScript. أدى ذلك إلى فقدان سياق الرابط المطلوب، وإخفاء أخطاء المسارات، والتعارض مع هدف المشروع في تقديم رسائل خطأ واضحة.

كانت صورة الإعلان الأصلية ذات أبعاد فعلية `1536×1024`، بينما أعلن `index.html` عنها بأبعاد `1080×1350`.

ملف `robots.txt` مُدار حاليًا من Cloudflare، ولذلك فهو خارج مصدر الحقيقة الموجود داخل الـRepository.

يفترض هذا القرار أن مالك المشروع أقر نشر عناوين السناتر وأرقام هواتفها علنًا.

## Decision

- تستمر الاستضافة مؤقتًا على GitHub Pages مع Cloudflare أمام الموقع.
- لا يُنفذ Router أو SPA fallback في هذه المرحلة.
- تبقى المسارات غير الموجودة بحالة HTTP 404.
- تُحذف القفزة التلقائية من `404.html`، وتُعرض بدلًا منها رسالة خطأ واضحة مع رابط للصفحة الرئيسية ورابط لقسم أماكن التواجد.
- تُصحح أبعاد صورة الإعلان المعلنة من `1080×1350` إلى `1536×1024` باعتبار ذلك إصلاحًا لخطأ بيانات قائم.
- يبقى ملف `robots.txt` مُدارًا من Cloudflare وخارج الـRepository.
- لا تُنشر مواعيد مجموعات في هذه المرحلة لأنها غير معتمدة.
- لا يُضاف رابط قناة واتساب لأنه غير متوفر.
- لا يُنفذ Routing أو JavaScript أو Build Step أو Dependency ضمن هذا القرار.

## Consequences

- يحصل الزائر على تفسير واضح عند فتح مسار غير موجود بدل نقله دون توضيح.
- تظل أخطاء الروابط والمسارات قابلة للاكتشاف بدل إخفائها بالتحويل القسري.
- تحتفظ GitHub Pages بسلوك HTTP 404 الصحيح.
- تساعد أبعاد الصورة الصحيحة المتصفح على حجز المساحة المناسبة قبل تحميلها وتقليل Layout Shift.
- يظل التحكم في `robots.txt` منفصلًا عن مصدر المشروع داخل الـRepository.
- لا توجد Migration أو قاعدة بيانات أو حالة مخزنة مرتبطة بهذا القرار.
- لا يدعم الموقع حاليًا مسارات تطبيق ديناميكية أو SPA fallback بحالة 200.

نظرًا لأن الدروس ستُنشر تدريجيًا، فإن النمط المرشح مستقبلًا هو إنشاء مجلد لكل درس يحتوي على ملف `index.html`. يمكن لهذا النمط توفير روابط نظيفة بحالة HTTP 200 دون Router ودون JavaScript.

هذا اتجاه مستقبلي مسجل فقط وغير منفذ ضمن هذه المرحلة، وللمهندس المعماري القادم حرية إعادة تقييمه.
