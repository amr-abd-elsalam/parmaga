# ADR-0015 — تعريف Dependency وتصنيف أدوات CI

## Status

Accepted.

يعلو على البنود السبعة المذكورة في قسم «البنود المعدَّلة» حصرًا، ولا يمسّ غيرها. ولا يُعلن أي ADR قائمًا Superseded.

## Context

يقيس المستودع نفسه بمسارين بلا متصفح: `python3 -m unittest discover -s tests -p 'test_*.py'` بنتيجة `Ran 146 tests` و`OK` وحالة خروج 0، و`python3 tools/verify_lesson.py .` بنتيجة `RESULT: PASS (0 errors)` على مرشح نشر واحد وحالة خروج 0. وسبعة بنود من V2 موروثة من `ADR-0013` باقية `Unknown` لأنها لا تُقاس إلا في متصفح.

وتنفيذ حزمة فحص متصفحي بالأدوات الشائعة يستلزم package manager. وهذا يصطدم بسبعة بنود سارية، أشدّها `ADR-0007` سطر 75 الذي يمنع «package manager» بالاسم.

ولفظ «Dependency» غير معرَّف في أي ADR من `ADR-0001` إلى `ADR-0014`. وفي الوقت نفسه يمارس `.github/workflows/verify-lessons.yml` ما يلي، وقد أقرّه Gate A حتى `run_number 58`: `runs-on: ubuntu-24.04` عند السطر 27، و`actions/checkout` مثبَّتًا بـSHA كامل عند السطر 31، و`actions/setup-python` مثبَّتًا بـSHA كامل عند السطر 37، و`python-version: '3.12'` عند السطر 39. أي أن المستودع يجلب كودًا خارجيًا ويثبّت toolchain في كل تشغيل CI.

فلو كان اللفظ يعني «كل ما يُجلَب»، لكان هذا الـworkflow مخالفًا منذ اعتماد CI. ولم يُعدّ مخالفًا. فالمستودع يعمل بحدٍّ فاصل يفرضه عمليًا ولم يكتبه. هذا القرار يكتبه، ولا يزيد عليه.

## Decision

**١. الفئة الممنوعة — Dependency.** حزمة تُعلَن في ملف manifest داخل شجرة المستودع، أو تُحلَّل من registry حزم إلى شجرة مثبَّتة داخل بيئة العمل، أو تُودَع vendored داخل الشجرة. تسري على وقت التشغيل والبناء والاختبار سواءً. المنع عليها باقٍ بلا تغيير، ويشمل بالاسم: `package.json` و`package-lock.json` و`node_modules` و`requirements.txt` و`pyproject.toml` وPlaywright وSelenium وأي متصفح يُجلَب عبر npm أو pip، وأي CDN.

**٢. الفئة غير الممنوعة — أداة CI.** ملف تنفيذي أو GitHub Action يُستدعى في تشغيل CI، بلا manifest حزم داخل الشجرة، ومثبَّت بـdigest أو image label، ولا يُنتج ولا يعدّل بايتًا واحدًا من البايتات المنشورة. هذه الفئة خارج نطاق منع Dependencies. وسابقتها مقيسة في `.github/workflows/verify-lessons.yml` عند الأسطر 27 و31 و37 و39.

**٣. الإذن المقيَّد.** يُؤذَن لأدوات الاختبار باستدعاء متصفح موجود في صورة الـrunner المعلَنة، عبر أعلام سطر الأوامر ومكتبة Python القياسية، ضمن الحدود الثمانية أدناه، ولا يُؤذَن بأكثر.

**٤. الحدّ الصريح.** لا يُكتب في هذا المستودع عميل WebSocket ولا عميل DevTools Protocol يدوي لتجنّب dependency. كلفة كود بروتوكول غير مُراجَع أعلى من كلفة dependency معلنة، والدخول فيها يحتاج قرارًا مستقلًا.

## البنود المعدَّلة — حصرًا، وعددها سبعة

1. `ADR-0007` سطر 75: «منع JavaScript الخاص بالمشروع: يُرفع المنع لهذه الصفحة عبر ملف خارجي واحد هو `assets/js/lesson-viewer.js`، بلا dependencies وبلا build step وبلا CDN وبلا package manager.» — يُفسَّر شقّ dependencies وحده بالتعريف في §١. وشقّ package manager وشقّ CDN وشقّ build step: سارية بلا مساس.
2. `ADR-0007` سطر 161: «البند الذي ينص على النشر «دون Router ودون JavaScript ودون Dependencies ودون Build Step»: يبقى منع Router والDependencies والBuild Step ساريًا بلا تغيير، ويُرفع منع JavaScript لصفحة الدرس وحدها عبر ملف خارجي واحد.» — يُفسَّر شقّ Dependencies وحده بالتعريف في §١. وشقّ Router وشقّ Build Step: ساريان بلا مساس.
3. `ADR-0003` سطر 49: «تُنشر الدروس على الأساس الثابت الحالي، دون Router ودون JavaScript ودون Dependencies ودون Build Step.» — يُفسَّر شقّ Dependencies وحده بالتعريف في §١.
4. `ADR-0003` سطر 159: «صفر JavaScript خاص بالمشروع، وصفر Webfonts، وصفر Dependencies، وصفر Build Step.» — يُفسَّر شقّ Dependencies وحده بالتعريف في §١.
5. `ADR-0003` سطر 210: «Dependencies.» — يُفسَّر بالتعريف في §١. وهذا السطر بندٌ في قائمة تأجيل نُفِّذت بنود أخرى منها فعلًا: «أي JavaScript» عند السطر 203، و«الاختبارات وCI» عند السطر 211، و«Lesson Viewer متقدم» عند السطر 202، و«أول محتوى تعليمي» عند السطر 201. عنوان القسم الحاوي لم يُقرأ ويبقى `Unknown`.
6. `ADR-0003` سطر 222: «يبقى الموقع HTML وCSS ثابتًا: صفر JavaScript خاص بالمشروع، وصفر Dependencies، وصفر Build Step، وصفر Router.» — يُفسَّر شقّ Dependencies وحده بالتعريف في §١.
7. `ADR-0005` سطر 289: «يبقى المستودع صفر Dependencies وصفر Build Step وصفر CI وصفر JavaScript.» — يُفسَّر شقّ Dependencies وحده بالتعريف في §١. وشقّ CI رُفع بالتنفيذ القائم، وشقّ JavaScript رُفع بـ`ADR-0007` سطر 161، وشقّ Build Step ساري بلا مساس.

عملًا بمنهج `ADR-0007` سطر 169: لا يُعدَّل ملف `ADR-0003` ولا `ADR-0005` ولا `ADR-0007` ولا أي ADR قائم؛ يُسجَّل هذا القرار لاحقًا ويعلو على البنود السبعة أعلاه دون غيرها.

## بنود مقيسة لا يمسّها هذا القرار — وعددها ستة

1. `ADR-0001` سطر 31: «لا يُنفذ Routing أو JavaScript أو Build Step أو Dependency ضمن هذا القرار.» — نطاقه قرار الاستضافة.
2. `ADR-0002` سطر 13 — وصف حالة في Context.
3. `ADR-0002` سطر 50: «إدخال Tailwind أو Sass أو أي Dependency أو Build Step.»
4. `ADR-0002` سطر 57 — نتيجة في Consequences.
5. `ADR-0003` سطر 9 — وصف حالة تاريخية في Context، لا بند قرار.
6. `ADR-0004` سطر 695: «عدم إضافة Webfonts أو Build Step أو Dependencies.»

## ما لا يفعله هذا القرار

لا يرفع منع package manager. ولا يرفع منع CDN. ولا يرفع منع Router. ولا يرفع منع Build Step. ولا يرفع منع Dependencies بمعناها المعرَّف في §١.

ولا يأذن بـPlaywright ولا Selenium ولا npm. ولا يعلن أي ADR قائمًا Superseded.

ولا يمسّ `assets/js/lesson-viewer.js` ولا `assets/css/parmaga.css` ولا أصول SVG ولا `courses/**/index.html` ولا `tools/verify_lesson.py` ولا `tests/*.py` ولا `.github/workflows/verify-lessons.yml` ولا `docs/content/manifests/**/*.json`.

ولا يُدخل Router ولا SPA ولا runtime content API ولا قاعدة بيانات ولا CMS ولا client-side lesson rendering.

ولا ينشئ `sitemap.xml` ولا فهارس Courses أو Term أو Chapter ولا Previous/Next بين الدروس.

ولا يحدّد محتوى assertions حزمة الفحص المتصفحي؛ ذلك نطاق قرار تنفيذي لاحق.

ولا يفصل عهدة الـManifest عن مصدر النص المؤلَّف الثنائي وبيانات النشر؛ تلك حاجة مسجَّلة في `docs/ai/ARCHITECT_EVIDENCE_LEDGER.md` وتتبع هذا القرار وتحتاج ADR أحدث، ولا يُحجز لها رقم هنا.

## الحدود الملزمة للأدوات المأذونة — ثمانية

كلٌّ منها يُثبَت بمخرج قابل للفحص لا بادّعاء:

1. غياب ملفات manifest الحزم من شجرة المستودع.
2. تطابق بصمات `sha256` للملفات الثلاثة المرصودة قبل التغيير وبعده: `assets/css/parmaga.css` و`assets/js/lesson-viewer.js` وصفحة الدرس المنشورة.
3. صفر build step يُنتج أو يعدّل بايتًا من HTML أو CSS أو JavaScript أو SVG.
4. استهلاك الملفات الساكنة كما هي عبر خادم من مكتبة Python القياسية.
5. عزل الـjob عن Gate A وخارج required checks حتى يمرّ ثلاث مرات متتالية على الشجرة نفسها.
6. طبع نسخة المتصفح في مخرج كل تشغيل.
7. حصر الـassertions الحاجبة على خصائص مستقلة عن نسخة المتصفح — مثل حضور نصّ في DOM وعدد مراجع SVG — ورفع الصور وملفات الطباعة artifacts للفحص البشري لا assertions.
8. قابلية التراجع بحذف ملفين.

## Consequences

الأثر على البايتات المنشورة صفر، ويُثبَت بالبصمات لا بالنظر. والأثر على 146 اختبارًا وعلى verifier صفر متوقَّع ويُقاس. والأثر على Gate A صفر بحكم العزل في الحدّ الخامس.

المكسب: أربعة بنود موروثة تصبح قابلة للقياس بكلفة تثبيت صفر — حضور النص العربي والإنجليزي في DOM بعد تنفيذ JavaScript، وحضور مراجع SVG الـ22 في DOM المُسلسل، والرسم بعرض هاتف، وإنتاج مستند طباعة.

الخسارة المسجَّلة: بنود V2 التي تحتاج DevTools Protocol — النقر على `data-viewer-prev` و`data-viewer-next`، والتركيز وترتيب لوحة المفاتيح، والأنماط المحسوبة، و`prefers-reduced-motion` — تبقى `Unknown`. ولا يزعم هذا القرار غير ذلك.

الخطر المسجَّل: `runs-on: ubuntu-24.04` يثبّت الـlabel لا بناء الصورة، فنسخة المتصفح تطفو داخله، بخلاف الـActions المثبَّتة بـSHA. التخفيف بالحدّ السادس والحدّ السابع، والخطر لا يزول.

المفترض غير المقيس: توفّر متصفح في صورة الـrunner، وعمل أعلام سطر الأوامر عليها، وسلامة تسلسل النص العربي في مخرج DOM. هذه ثلاثة `Unknown` تُقاس في التنفيذ ولا تُفترض.

## التراجع

حذف ملف الـworkflow المضاف وملف الاختبار المضاف. ولا شيء غيرهما يعود.

والتراجع عن التعريف نفسه يجري بقرار لاحق يعلو عليه، لا بتعديل هذا الملف.

## مُشغِّل إعادة الفتح

على عرف `ADR-0011` سطر 108 — «يُرفع إن ثبت» — يُعاد فتح مسألة الإذن بـpackage manager عند توفّر تقرير مقيس يُسمّي بندًا محدَّدًا من بنود V2 السبعة تعذّر قياسه بأعلام سطر الأوامر وحدها. وحتى ذلك الحين لا يُرفع المنع.
